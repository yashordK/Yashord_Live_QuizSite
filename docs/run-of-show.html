The Yashord Quiz

Everything you need to run the session. The middle section is the loop you repeat 24 times — if you read nothing else, read that.

A The three screens

Students — put this on the board https://your-app.vercel.app Name, roll number, and the join code QUIZ01. The screen previews the roll it will store as they type — tell them to remember that form.
You — laptop or phone, kept private https://your-app.vercel.app/host/control Shows the answer key. Never put this on the projector.
Projector — full screen, no controls on it https://your-app.vercel.app/present Safe to display. The answer key is not in this page until you reveal it.

Log in once at /host/login with your host password. The login lasts 12 hours and works from any device — if your laptop dies, log in on your phone and carry on from the same place.

B 30 minutes before

  • Open /api/health — should say ok: true, questions: 24, phase: IDLE.
  • Set the roll prefixes in the host panel → Session → Roll prefixes. Enter them comma-separated, e.g. 22CS, 22IT. Students then tap their prefix and type only the digits. Do this before anyone joins.
  • Open /present on the projector and full-screen it (F11). Check the back row can read it.
  • Open /host/control on your laptop. Confirm the phase badge says IDLE.
  • Self-join once from your phone to prove the whole path works, then delete yourself from the Participants tab.
  • Write the URL and code large on the board — students mistype URLs more than anything else.
  • Have the questions in a PDF as a backup if the venue wifi collapses.

C The loop — repeat for all 24

  1. 1 Start / Next Question Question text appears. Options stay hidden so everyone reads before racing.
  2. 2 Show Options The answer window opens and the timer starts. This is the only phase that accepts answers.
  3. 3 Lock Answers Optional — the timer closes the window on its own. Use it to cut a question short.
  4. 4 Pause on the distribution bar This is your teaching moment. You can see how many chose A/B/C/D before anyone knows the answer. Ask the room why — then reveal.
  5. 5 Reveal Answer Correct option turns green everywhere. Students see their own result and points.
  6. 6 Show Solution Displays the explanation. Skip it when you're running long.
The leaderboard appears on its own

After questions 5, 10, 15 and 20 it interrupts automatically — press Next once to show it, and again to move to the next question. Show Leaderboard works at any time too.

Reveal is one-way

Once you reveal, that question can never reopen for answers. You can go back a question, but you can't take the answer key back. Reveal only when you mean it.

E When something goes wrong

They sayYou do
"My screen is stuck"Press Re-broadcast state. If not, it self-corrects within 5 seconds anyway — every device re-checks the server on a timer.
"It says quiz is full"You're at 185. If they joined before, entering the same roll always lets them back in even when full.
"I lost my score"They joined twice with different roll spellings. Have them re-enter the roll exactly as the join screen showed it — the screen previews it as they type.
"My prefix isn't listed"They tap "My roll number looks different" on the join screen and type the whole roll. Always available, so nobody is ever locked out by the prefix list.
You set a prefix wrongFix it in the host panel and press Save — it takes effect immediately, no redeploy. Anyone who already joined keeps their existing roll.
"I got disconnected"Rejoin with the same roll. Score is intact and they land wherever the class currently is.

Running out of timeSkip Question on the ones you're happy to drop. Numbering adjusts for everyone.
Your laptop diesOpen /host/control on your phone, log in, continue. The state is on the server, not your laptop.
Projector shows the wrong thingRefresh /present. It has no controls, so it can only ever mirror the server.

F The moment it ends

Export the CSV before you close anything

Host panel → Export CSV. One row per student with per-question results. A free Supabase project pauses after inactivity, and you do not want to be recovering data later.

  • Press 🏆 Show Top 3 for the podium moment, and let it finish before you talk over it.
  • Press End session — students see final scores.
  • Leave /present on the final leaderboard while people file out.

G How scoring works

wrong or unanswered  →  0            (no negative marking)
correct              →  100 + up to 50 for speed
  • Fast correct answer ≈ 150. Correct at the buzzer ≈ 100. Wrong = 0.
  • Correctness beats speed by design: a slow correct answer still beats a fast wrong one by 100 points.
  • Timing is measured on the server, so a student with a wrong phone clock gains nothing.
  • Ties share a rank — two students on 1,200 are both 2nd, and the next is 4th.

If someone asks about questions they missed while disconnected: they score 0 on anything that fully passed, but can answer anything still open. That's the rule, and it's worth saying out loud once.
